# Getting help

- **Usage questions:** open a [GitHub Discussion](https://github.com/AnimeshShaw/quantum-safe-ts/discussions) (or an issue labelled `question` if
  Discussions are not enabled). Include your runtime, bundler and a minimal snippet. Never paste real keys or plaintext.
- **Bugs:** use the bug-report issue template.
- **Compatibility with quantum-safe-py:** use the compatibility-report template and attach the bytes (hex) that differ.
- **Security vulnerabilities:** not in public. Follow [SECURITY.md](SECURITY.md).
- **Which package do I need?** `quantum-safe-ts` is the library. `quantum-safe-audit` scans code for classical cryptography.
  `quantum-safe-mcp` exposes the scanner and guidance to AI coding agents.

This is a volunteer-maintained project: there is no support SLA.
